## Key Lessons / Notes
- SQLite requires single quotes for string literals (not double quotes) — kept biting us
- better-sqlite3 needs native compile on Render — use `--build-from-source` flag
- Render free tier has no persistent disk — always use Starter ($7) with disk mounted at /var/data
- GitHub fine-grained tokens don't work well for us — always use classic tokens (ghp_...)
- training_plan was getting double/triple JSON encoded — fixed with recursive parser
- Always use `openclaw-gateway` (with dash) in systemctl, not `openclaw`
- Carly responds to emojis as reactions (👍 = acknowledged, ❤️ = likes it)
- Carly prefers direct, no-fluff communication
- "assume i always want room to add a task unless i say otherwise" — every checklist gets an add option
